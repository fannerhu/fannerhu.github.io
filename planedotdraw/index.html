PlaneDot Draw 中文 Documents

Graphics are an intuitive representation of information.
PlaneDot Draw can be used to draw graphics.
Currently, only the iPad version is available.

Key features:
Editable vector graphics: move, rotate, scale, flip, arrange and editing border width, border color, fill color, etc.
Duplicate, hide and delete layers; drag a layer to change its order.
Drag resources and drop onto the canvas.
Move the endpoints to modify the shape's contour.
Generate voronoi diagrams, pie charts, and other visualizations by inputting data.
Combine shapes: union, subtraction, intersection and symmetric difference.
JPEG and PNG import and export.
Graphics file create, save, open and import.
